Hidden Gems of Malaysia Travel App

A mobile app that helps tourists discover lesser-known, authentic destinations
across Malaysia — plan trips, check in at places, collect badges and quizzes,
track a travel journal, and connect with friends along the way.

-------------------------------------------------------------------------------

GitHub repo: https://github.com/ligitpizza/hidden-gem-tourist-app

-------------------------------------------------------------------------------

How to run:

1. Extract the Project Folder.
2. Open the Project Folder in any IDE that supports Flutter.

3. Run Project in Android Studios and connect to a Virtual Device.

Recommended Device:
Pixel 9 Pro XL API 35
Android 15.0 VanillaIceCream

OR

(Fastest Way: Recommended)

If you have an actual Android phone, you can plug it into your
computer with a USB cable instead (turn on "Developer options" → "USB
debugging" in your phone's Settings first). Then allow transfer files.

OR

Run the following command to build a apk release then follow the steps
to locate the file:
    flutter build apk --release

Once it finishes, the file will be at:
    build/app/outputs/flutter-apk/app-release.apk
